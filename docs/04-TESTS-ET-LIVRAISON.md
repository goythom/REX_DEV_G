# Checklist de tests et livraison

## Parcours

- [ ] Le parcours principal fonctionne du début à la fin.
- [ ] Tous les boutons ont une action correcte ou un état désactivé expliqué.
- [ ] États vide, chargement, erreur, succès et annulation vérifiés.
- [ ] Rechargement, retour navigateur et visiteur neuf testés.
- [ ] Données de démonstration clairement signalées.
- [ ] Intégrations réellement exercées, pas seulement simulées.

## Responsive et pixels

- [ ] Ordinateur, iPad et petit écran selon le périmètre.
- [ ] Safari réel ou vérification explicite de ce qui n'a été testé qu'en émulation.
- [ ] Aucune barre de défilement horizontale accidentelle.
- [ ] Textes, images, pop-ups et boutons non coupés.
- [ ] Contrôles tactiles, stylet et clavier utilisables.
- [ ] Toutes les langues et les variantes de contenu prévues vérifiées.
- [ ] Captures réellement inspectées après les dernières corrections.

## Qualité technique

- [ ] Build et tests réussis.
- [ ] Console sans erreur liée au parcours testé.
- [ ] Chargement et actions assez rapides sur le matériel cible.
- [ ] Fichiers temporaires retirés ; sources et lockfile présents.
- [ ] Aucun secret dans les fichiers, captures ou historique à publier.

## Site publié

- [ ] Job de déploiement terminé avec succès.
- [ ] Version / commit publiés identifiés.
- [ ] Bon domaine et bonne route, pas une ancienne preview.
- [ ] Parcours testé sur le site réellement publié.
- [ ] Liens de partage existants conservés ou migration documentée.
- [ ] Limites restantes annoncées et retour arrière possible.

## Fermeture

- [ ] README du projet à jour : lancement, tests, build, services.
- [ ] État du dépôt distant vérifié.
- [ ] REX et décisions mis à jour.
