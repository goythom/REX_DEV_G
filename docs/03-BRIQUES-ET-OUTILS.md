# Briques et outils

Ce catalogue décrit des usages possibles. Il n'affirme ni installation, ni gratuité actuelle, ni licence vérifiée pour une version donnée.

| --- | --- | --- |

| Boutique avec back-office | Medusa | Hébergement, base de données, RAM, exploitation |

## Choisir sans empiler

Installer uniquement ce qui résout un problème identifié. Un outil de feedback ne remplace pas les tests ; un générateur de maquettes ne garantit pas la fidélité ; un environnement cloud ne garantit pas un lien permanent.

Pour chaque brique retenue : version, lien officiel, licence lue, limites, alternatives, méthode de remplacement. Pour un produit commercial, vérifier les obligations des licences ; ne pas intégrer une dépendance incompatible par habitude.
